# 台本のコマンド

Botの応答の行のうち、`[` で始まる行はコマンドの配列です。1つのコマンドは、先頭がコマンド名の配列です。

```json
[["set","ruu",{"f":"ruu-smile.svg","x":0.36,"y":0.33,"w":0.27,"h":0.48,"id":5,"effect":"scale"}],["wait",0.5]]
```

台詞の行とコマンドは、書いた順に1つずつ実行します。台詞は、利用者が吹き出しを押すまで待ちます。

## どのページでも使えるコマンド

| コマンド | 引数 | 動き |
|---|---|---|
| `message` | 文字列 | 台詞を出す（台詞の行と同じ）。台詞を出せるのは、Roomと、台詞の吹き出しを置いた作品固有のページだけ |
| `wait` | 秒数 | 待つ。`"1.5"` のような数の文字列も使える |
| `go` | path またはURL | そのページへ移る。`/` で始まるpathは、配置先（`--base`）からのpathになる。開けるのは path と http(s) のURLだけ。移るので、`go` の後ろの台本は実行せず、移り終わるまで物のタップなどから action を送らない |
| `send_chat` | 文字列 | 利用者の発言としてトークへ送る（LIFFは閉じない） |
| `command` | action | そのactionの台本を取り寄せ、今の台本の後ろに続ける |
| `preload` | path | 画像を先に読み込む。`/` で始まるpathは、作品の `public/` からのpath |
| `set_hud` | 項目名, 値 | ステータス表示の値（`lv`・`n_words` など、`get_status` の項目）を変える。変えた後の状態が `get_status` の形でなければ（`words` にことばの形でない値を入れた、など）、台本を止める |

`command` の台本は、今の台本の**末尾**に加わります。`command` の後ろに書いたコマンドが先に実行され、その後に取り寄せた台本が続きます。応答の5行の制限を超える台本は、最後の行に `command` を書いて続きを取り寄せます。

## Roomのコマンド

| コマンド | 引数 | 動き |
|---|---|---|
| `set` | 名前, 物 | 物を置く・置き換える。`null` なら取り除く。物の形でない時（オブジェクトでない、`effect` が文字列でない）は台本を止める |
| `condition` | action, 条件の配列 | 物を運ぶ謎を始める |

### Roomの物

`roomObjects` の値と `set` の2つ目の引数は、次の項目を持つオブジェクトです。座標と大きさは、部屋（額縁の内側）に対する割合です。

| 項目 | 内容 |
|---|---|
| `f` | 画像のファイル名（`<dataDir>/room/`）。無ければ画像を描かない（`onclick` を付ければ、見えないタップの領域になる） |
| `x`・`y` | 左上の位置（0〜1）。`"0.5"` のような数の文字列も使える |
| `w`・`h` | 幅と高さ（0〜1） |
| `id` | 重なり順。大きいほど手前。額縁は10で、10以上の物は額縁より手前に描く |
| `onclick` | タップした時に送るaction |
| `effect` | 演出（下の表）。カンマで区切って複数書ける |
| `visible` | メニューのボタンを出す（下の「メニューのボタンを出す」） |

`set` は物を丸ごと置き換えます。位置を変えずに絵だけ変える時も、`x`・`y`・`w`・`h` を書きます。ドラッグで動かした物も、`set` で置き換えると、書いた位置に戻ります。

### 演出（effect）

| 名前 | 動き |
|---|---|
| `flash` | 画像が白く光る |
| `glow` | 画像がふわっと明るくなる |
| `scale` | 弾むように大きくなって戻る |
| `shake` | 左右に揺れる |
| `room_flash` | 部屋全体が白く光る |
| `room_flash_strong` | 部屋全体が強く光る |

`flash` と `glow`、`scale` と `shake` は、それぞれ同時に1つだけ効きます（後に書いた方）。組み合わせるなら、`glow,scale` のように別の組から選びます。

ほかの名前（英数字と `_` `-`）は、作品の演出になります。物に `fx-<名前>` のクラスを付けるので、作品の `skin.css` にアニメーションを書きます。標準の演出と重ねられます。

```css
/* ["set","ruu",{"f":"ruu.svg",...,"effect":"sparkle"}] で、ふわっと光る */
.fx-sparkle {
  animation: sparkle 1.2s ease-out;
}

@keyframes sparkle {
  from {
    filter: drop-shadow(0 0 1.5rem #fff6c8);
  }
}
```

演出は、物が `effect` 付きで置かれた時に一度だけ再生します。表示の前に実行した `set` の演出は、画面を表示してから再生します。同じ物に同じ `effect` の文字列をもう一度 `set` しても、ページを開き直すまで再生しません。続けて同じ演出を見せる時は、`shake` と `shake,shake` のように文字列を変えてください。

### condition（物を運ぶ謎）

```json
[["condition","jar_done",[["position",["star",0.17,0.6,0.255,0.71]]]]]
```

条件の配列の要素は `["position", [物の名前, x1, y1, x2, y2]]` です。範囲は部屋に対する割合（0〜1）で、物の座標と同じく数の文字列も使えます。対象の物がドラッグで動かせるようになり、物の左上が範囲に入ると、範囲の中央へ吸い付いて部屋が光ります。条件は、始めた時にも一度確かめます。

すべての条件を満たすと、actionを送ります。Botが受け付けたのを確かめてから、`condition` の後ろのコマンドを実行し、その後にactionの台本が続きます。Botへ伝えられなければ、台本を止めます。

ドラッグでは、物の中心が部屋の外へ出ないようにします（物の半分までは外へ出せます）。解いた後も、物はドラッグで動かせるままです。

条件が空、読めない、対象の物が無い時は、満たしたことにせず台本を止めます。

### メニューのボタンを出す

Roomの下のボタンは、`get_status` の `menu` に並んだIDのものだけを出します（`menu` が無ければ、何も出しません）。台本の途中で出す時は、ボタンのIDと同じ名前で `visible` を `set` します。ボタンは、大きさと透明度を変える演出付きで現れます。

```json
[["set","messages",{"visible":true}]]
```

この `set` は画面の中だけの変化です。次に開いた時にも出すため、シナリオで `menu` にIDを加えてください。

メニューのボタンのIDと、Roomの物の名前は、同じ名前の空間を使います。物にボタンと同じ名前を付けると、その物の `visible` でボタンが出ます。

## ことば帳のコマンド

| コマンド | 引数 | 動き |
|---|---|---|
| `set` | キー, 値 | ことばを加える・変える。前の値の `w`・`s` は、書かなければ引き継ぐ（`f`・`onclick` などは引き継がない）。値が `null` の時は、`w`・`s` だけを引き継いだ、ふつうのことばに戻す（ことばは消えない）。値が読めない時（`w`・`s`・`f`・`onclick` が文字列でない、など）は台本を止める |
| `disable_click_words` | なし | ことばをタップしてもトークへ送らないようにする（`onclick` のあることばは動く） |

## 表示の前に実行するコマンド

ページを開いた時の台本のうち、先頭から続く `set`・`set_hud`・`preload`・`disable_click_words` は、画面を表示する前に実行します。画像の読み込みも待つので、部屋が描き変わる途中を見せません。最初の台詞や `wait` などから先は、表示してから実行します。

## 不具合の時

受け付けないコマンド、引数の誤り（行き先の無い `go`、秒数を読めない `wait`、文字列でない `send_chat` など）、取り寄せの失敗、台詞を出せないページの台詞では、台本を止めます（[連携仕様](protocol.md#7-不具合の時に止める)）。
